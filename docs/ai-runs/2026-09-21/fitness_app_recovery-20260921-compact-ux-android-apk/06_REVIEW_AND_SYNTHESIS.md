# סינתזה
המוצר נשאר local-first ו-single-source: אותו `src/` משרת את האתר ואת ה-APK. הסיכון העיקרי שנותר הוא **פיצול נתונים** בין הדפדפן לאפליקציה (שני origin-ים) עד שסנכרון Phase 1 בענן יאומת — לכן ההוראות לאריאל מדגישות מעבר חד-פעמי ומקור אמת אחד. חתימת ה-APK היא debug (פנימי) — מספיק להתקנה ידנית, לא ל-Play. הפרסום ל-Lovable עדיין חסום מהסשן (החשבון המחובר אינו רואה את הפרויקט) — כמו בריצה הקודמת, אריאל לוחץ Publish.
